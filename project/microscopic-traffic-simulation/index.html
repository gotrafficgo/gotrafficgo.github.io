ATSimu: A Network-Scale Microscopic Traffic Simulator

Zhengbing He · Early Open-Source Research Software · 2010–2011 · Visual C++ / MFC · MIT License

ATSimu is an early network-scale microscopic traffic simulation platform supporting XML-based networks, microscopic vehicle movements, traffic demand, routing, intersection operations, detectors, and day-to-day commuter adaptation. The original source releases are preserved on GitHub for research reference, reproducibility, and education.
